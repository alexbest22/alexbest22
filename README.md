## Projetos em destaque

### Consulta NFE

**Projeto próprio · Automação**

Automação de consultas e download de planilhas da SEFAZ para reduzir etapas manuais em tarefas recorrentes.

**Minha atuação:** desenvolvimento da automação em Python, com navegação por Selenium e leitura com OCR.

**Tecnologias:** Python · Selenium · OCR

[Explorar o projeto →](https://github.com/alexbest22/consulta-nfe)

### Ergo App

**Projeto em equipe · Aplicação desktop de ergonomia**

Aplicação para acompanhar postura e atividade de digitação, com interface em React, backend nativo em Rust e persistência local em SQLite.

**Minhas contribuições:** persistência das métricas de digitação, correções no ciclo de vida e na duração das sessões de monitoramento, integração entre frontend e backend e testes automatizados.

**Tecnologias:** Tauri · Rust · React · TypeScript · SQLite

[Repositório →](https://github.com/otaviocostao/ergo-app-tauri) · [Minhas contribuições →](https://github.com/otaviocostao/ergo-app-tauri/commits?author=alexbest22)

### AVA UNIFAN

**Projeto em equipe · Ambiente virtual de aprendizagem**

Plataforma com frontend e API para apoiar a gestão de cursos, turmas e atividades acadêmicas.

**Minhas contribuições:**

- **Frontend:** integração da área do coordenador com o backend, incluindo cursos, busca de alunos, turmas, disciplinas e ajustes nos horários.
- **Backend:** ajustes em endpoints de cursos, mural de avisos, filtros e validações de regras de negócio.

**Tecnologias:** Next.js · React · TypeScript · Tailwind CSS · Node.js · NestJS · PostgreSQL · Supabase

[Frontend →](https://github.com/RiosWesley/AVA-UNIFAN) · [API →](https://github.com/otaviocostao/ava-backend)
